=== exams/si664_midterm-20181023.md ===
# SI 664 Midterm, Fall 2018
Sections:
1.0 Preliminaries (open web, problem format, work folder, gotchas)
2.0 SQL SELECT statement problems (e.g., Indian heritage sites inscribed 2000-present; sub-Saharan site counts by region/category; heritage site counts by country, top 25)
3.0 Django ORM QuerySet problems (equivalent queries expressed via Django ORM instead of raw SQL)
4.0 Django heritagesites app (add new pages, URLs, templates, navbar link)

Course centers on a running example app ("heritagesites", a UNESCO World Heritage Sites database) used to teach SQL, the Django ORM, and building a Django web app + REST API.
